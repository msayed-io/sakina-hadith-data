# Brand assets

The repository identity is intentionally separate from the Sakina application UI while following the same calm scholarly direction: parchment surfaces, espresso ink, and restrained sand-brass highlights.

## Mark

`assets/sakina-hadith-mark.png` is the transparent symbol for avatars, repository identity, app download cards, and documentation headers. It combines an open book with layered database storage and a central light-of-knowledge motif.

## Cover

`assets/sakina-hadith-cover.png` is the wide editorial cover for README pages, documentation landing pages, and repository presentations. It has a quiet left side intended for an overlaid title when used outside GitHub Markdown.

## Usage rules

Keep the mark on calm, high-contrast backgrounds. Do not recolor it, add text inside it, distort its proportions, or place it over busy imagery. Use the cover as a wide banner rather than as an application icon. The assets are visual identity aids for this data repository; they do not change the database schema, release assets, or application behavior.
